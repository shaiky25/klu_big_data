Slide 1 / Concept Setup

Predicting Churn: Linear vs. Logistic Regression

Why we cannot use standard linear regression for binary (Yes/No) business decisions.

Linear Regression (lm())❌ Incorrect

Equation: Y = β₀ + β₁X

  • Predicts unbounded values from -∞ to +∞.
  • Can output impossible probabilities (e.g. 132% churn risk or -15% chance).
  • Violates constant variance assumptions (heteroscedasticity).
Logistic Regression (glm())✅ Correct

Equation: ln(p / (1 - p)) = β₀ + β₁X

  • Applies the Logit Link Function to form an S-curve (Sigmoid).
  • Outputs are mathematically locked between 0.0 and 1.0 (0% to 100%).
  • Models the probability of a customer canceling service.
Instructor Note to Students
Use linear regression when asking "How much revenue will this customer generate?" Use logistic regression when asking "Will this customer leave us next month?"
Slide 2 / Hypothesis Formulation

Defining Hypotheses Before Modeling

Establishing the baseline assumption of no effect versus our research claim.

Mathematical Hypotheses

Null Hypothesis (H₀):

β_MonthlyCharges = 0

Alternative Hypothesis (Hₐ):

β_MonthlyCharges ≠ 0

The same hypothesis structure applies to all candidate predictors (Tenure, Contract Type, Payment Method).

Decision Rule in Plain English
Condition Statistical Action Business Takeaway
p-value < 0.05 Reject H₀ The feature has a statistically confirmed impact on churn.
p-value ≥ 0.05 Fail to Reject H₀ The feature's relationship is likely random noise; do not base business strategy on it.
Key Principle
The Null Hypothesis (H₀) is the default skepticism. We only claim a variable drives churn if our sample data provides overwhelming statistical evidence (p < 0.05).

Slide 4 / Model Fitting

The glm() Function Anatomy

Breaking down every argument required to fit a logistic regression model.

R Syntax
churn_model <- glm(
  formula = Churn ~ Tenure + MonthlyCharges + Contract,
  data    = churn_df,
  family  = binomial(link = "logit")
)
Parameter Breakdown
ParameterRole
Churn ~ ... Target variable (Y) predicted by feature inputs (X).
+ Includes predictors simultaneously in the multivariable equation.
family = binomial Specifies a binary target distribution (0 vs. 1).
link = "logit" Applies the log-odds transformation curve.
Common Student Bug
Forgetting family = binomial causes R to run standard Ordinary Least Squares (OLS) regression instead of logistic regression.

Step-by-Step Interpretation
  1. Check Significance: Look at Pr(>|z|). All p-values are < 0.001 (indicated by ***). We reject H₀ for all four variables.
  2. Check Direction (Estimate):
    • +0.0195 (MonthlyCharges): Higher bills increase churn log-odds.
    • -0.0381 (Tenure): Longer tenure decreases churn log-odds.
  3. Note on Units: Estimates are currently in log-odds, which are hard for business leaders to digest.
Quick Reading Rule
Stars (***) tell you if the feature is real; the sign (+ or -) tells you if it hurts or helps customer retention.
